# Tic-Tac-Toe Endgame data

`tic-tac-toe.csv` is a 958-row, 10-column copy of the Tic-Tac-Toe Endgame records, with nine categorical board positions and one binary outcome. The columns `TL`, `TM`, `TR`, `ML`, `MM`, `MR`, `BL`, `BM`, and `BR` locate positions from top left to bottom right. `x` and `o` denote marks; `b` denotes a blank. In this copy, `true` means X won and `false` means X did not win. The original UCI labels are `positive` and `negative` for the same target concept.

Source copy: [datasets/tic-tac-toe at commit `01e1baefb3ee54ae007974f53ab5f1deaf89c5e6`](https://github.com/datasets/tic-tac-toe/blob/01e1baefb3ee54ae007974f53ab5f1deaf89c5e6/data/tic-tac-toe.csv), file blob `1424ca4bc245c896e5613a11570c8763cfbd71b8`. The copy has 626 `true` and 332 `false` records. Its SHA-256 checksum is `8a08a15f578d5cebb8beee180792daaa09fabef829fb23a61c8475b445d6c017`.

Original dataset: David W. Aha (1991), [Tic-Tac-Toe Endgame, UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/101/tic%2Btac%2B), DOI [10.24432/C5688J](https://doi.org/10.24432/C5688J). UCI lists the dataset under the Creative Commons Attribution 4.0 license.
